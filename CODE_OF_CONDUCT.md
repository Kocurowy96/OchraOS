# Code of conduct

OchraOS follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, welcome newcomers, and keep criticism
about the code, not the person. Harassment, insults and discrimination are not tolerated.

Report problems privately to the project maintainer through GitHub. Reports are handled
confidentially.
