# OchraOS

A hobby operating system written from scratch in Rust. Its kernel implements the Linux
syscall ABI, so Linux binaries run natively — with Wine and Steam as long-term goals.
x86_64, UEFI.

**Status:** stage 0 — nothing boots yet.
