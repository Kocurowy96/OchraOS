## Stage 1, pitstop P2 (steps 3–5)

### Done

- Frame allocator (`frame/src/mm/frames.rs`): bitmap over usable RAM, owned `Frame` handles
  freed on drop; self-test `frames` (alignment, distinct frames, separate memory, counts).
- Own page tables (`frame/src/mm/paging.rs`): kernel image per segment (code r-x, rodata r--,
  data rw-, physical pages looked up in Limine's tables), direct map with 2 MiB pages at
  Limine's offset, CR3 switched. Kernel stacks in 64 KiB slots with a guard page below; the
  double fault handler moved to such a stack (TSS is now updatable).
- Crash tests moved to `frame/src/selftest.rs`; new: `wx`, `nx`, `guardpage`, `smep`, `smap`.
- Kernel heap (`frame/src/mm/heap.rs`): first-fit free list with merging, grows on demand;
  `kernel` uses `alloc`; self-test `heap` (Box/Vec/String, 4 KiB alignment, no overlap,
  growth, no leak, merged back into one block). A broken merge was caught by the self-test.
- `cargo xtask test`: 9 tests (boot + 7 crash tests + KASLR).

### Broken / open

- The boot stack (Limine's) has no guard page yet; the boot code becomes a task with a guarded
  stack in step 8.
- Bootloader-reclaimable memory is never reclaimed; kernel stacks are never freed; the heap
  never shrinks.
- Locks (frames, page tables, heap) are not yet IRQ-safe: step 6.

### Next

- P3: interrupts (PIC masked, LAPIC with x2APIC/xAPIC), IRQ-safe locks, calibrated LAPIC timer.


## Stage 1, pitstop P3 (steps 6–7)

### Done

- `IrqMutex` (`frame/src/sync.rs`): interrupts off while held; replaces `spin::Mutex` for COM1,
  frames, page tables and heap.
- Interrupt entry for vectors 32–255: 224 stubs generated with `global_asm!` `.rept`, sharing
  the exception entry path; handlers registered per vector (`interrupts::set_handler`), EOI
  after the handler, spurious vector ignored.
- Legacy PIC remapped and masked; local APIC enabled in x2APIC mode, xAPIC fallback with an
  uncached MMIO mapping (new PML4 slot 510 for device registers).
- LAPIC timer calibrated with PIT channel 2, periodic at 100 Hz; kernel `time` module counts
  ticks.
- Self-tests `interrupts` (3 self-IPIs through the APIC) and `timer` (ticks keep coming; no
  timing assertions). New boot test `xapic` (`-cpu max,-x2apic`). 10 tests in total; also
  checked by hand under pure TCG.

### Broken / open

- Nothing known broken. `halt_forever` still ends the boot with interrupts off; the idle loop
  comes with the scheduler.

### Next

- P4: scheduler (kernel tasks on guarded stacks, context switch, round-robin on the timer),
  boot test for A/B interleaving, tag `stage-1`.


## Stage 1, pitstop P4 (steps 8–9): stage 1 done

### Done

- `ochra_frame::task`: tasks on 32 KiB `KernelStack`s with a guard page, a naked `switch`
  (callee-saved registers + stack pointer), a trampoline that starts new tasks with
  interrupts on, `start` leaves the boot stack for good.
- `kernel::sched`: round-robin run queue (`IrqMutex<VecDeque<Arc<Task>>>`), switch on every
  timer tick; the boot code ends by starting the tasks, `idle` replaces `halt_forever`.
- EOI is now sent before the interrupt handler (the handler may switch tasks).
- Tests: tasks A and B log 5 steps each, `cargo xtask test` checks they interleave (order
  only; 9 switches locally); crash test `taskstack` (task stack overflow into its guard page
  ends in a double fault on the IST stack). 12 tests in total. Mutation check: with switching
  disabled the scheduler test fails.

### Broken / open

- Tasks cannot exit or sleep; there is no blocking, only time slices.
- "Processes and threads" in the stage 1 description arrive with user space in stage 2.
- Bootloader-reclaimable memory, kernel stacks and heap growth are still never given back.

### Next

- Stage 1.5: SMP (application processors, per-CPU GDT/TSS/IST and data, scheduler on every
  core).


## Stage 1.5, pitstop P1 (steps 1–3)

### Done

- `ochra_frame::smp`: the MP request; every AP enters `ap_entry` on Limine's stack, loads
  the kernel page tables, its own GDT/TSS (double fault stack with a guard page), the shared
  IDT and the protections, then calls the kernel's `ap_main` (which halts for now).
- `ochra_frame::cpu_local`: `PerCpu` through the GS base (index, APIC ID, current task);
  `task` keeps the current task there instead of a global. The log shows the CPU
  (`[INFO  cpu2]`), and so do crash reports (`on cpu 1`).
- The crash-report writer takes the COM1 lock when it can (reports were mixed byte by byte
  with another CPU's log).
- `cargo xtask build/run --release`; QEMU runs with 4 cores.
- Tests: self-test `cpus` (every CPU finds its own per-CPU data), crash test
  `apdoublefault` (double fault on cpu 1, on its own stack), boot test `onecpu` (`-smp 1`).
  14 tests in total.

### Broken / open

- APs halt with interrupts off after reporting in; no APIC, timer or tasks on them yet.
- A crash on one CPU does not stop the others yet (step 5).
- `task::switch_to` still assumes one CPU (step 6).

### Next

- P2: local APIC and timer on every CPU, stop all CPUs on panic.


## Stage 1.5, pitstop P2 (steps 4–5)

### Done

- `apic::init` runs on every CPU (mode decided and mapped once, x2APIC bit set per core);
  `apic::start_timer` calibrates only on the first call. APs enable their APIC and timer and
  wait for interrupts. Ticks are counted per CPU (`kernel::time`).
- The boot CPU sets up its APIC and timer before starting the APs.
- Crash path: `smp::stop_other_cpus` sends an NMI to all other CPUs, which halt in the NMI
  handler and confirm; reports and panics print `stopped N other CPUs`.
- Tests: self-test `timer` now requires ticks on every CPU; crash tests expect
  `stopped 3 other CPUs`. Mutation check: with the NMI handler not confirming, four crash
  tests fail ("stopped 0 of 3").

### Broken / open

- An NMI sent while an AP is still parked in Limine (a crash during `start_other_cpus`)
  would reach Limine's IDT; not handled.
- Tasks still run only on the boot CPU (step 6).

### Next

- P3: scheduler on every CPU with one global run queue, boot test for tasks on several CPUs,
  tag `stage-1.5`.


## Stage 1.5, pitstop P3 (steps 6–7): stage 1.5 done

### Done

- `task`: an `on_cpu` flag per task; `switch` clears it after the previous task is saved and
  its stack left; `claim` waits for it before a CPU runs a task. `task::start` works on
  every CPU.
- `sched`: one global run queue; the boot CPU queues the tasks (A, B and one idle task per
  CPU) and opens the queue; the APs wait for that and start scheduling too.
- Tests: with `-smp 4` the steps of tasks A and B run on several CPUs (locally all four);
  with `-smp 1` they interleave (timer switching). 15 tests in total. Mutation check: APs
  that do not join the scheduler make the SMP test fail.
- Checked for flakiness: four full test runs, 30 boots with KVM and 15 with TCG only, all
  fine.

### Broken / open

- Once, during a mutation run, one test boot printed no kernel banner at all; it could not
  be reproduced since (see above). Watch CI for it.
- The idle tasks wander between CPUs (any idle task is as good as another).
- TLB shootdown, per-CPU run queues, task exit and blocking: later stages.

### Next

- Stage 2 (Linux ABI): plan to be agreed with the owner first.


## Stage 2, pitstop P1 (first code in ring 3)

### Done

- Stage 2 plan agreed, with the owner's additions recorded in the roadmap checklist and in
  `decisions.md`; KPTI note in `security.md`.
- `mm::user::UserSpace`: per-process page tables sharing the kernel half; map, unmap (returns
  the frames), protect, translate; dropping frees pages and tables.
- `mm::tlb`: TLB shootdown by IPI, only when another CPU has the space loaded.
- Tasks may carry a user address space; CR3 and RSP0 (TSS and per-CPU) change on switches.
- GDT user segments (Linux selectors), `syscall` MSRs on every CPU, entry with `swapgs`,
  common frame with interrupts/exceptions, return always through `iretq`.
- `user_mode`: `UserContext`, syscall and fault handlers, `copy_from_user`/`copy_to_user`
  with SMAP and a fixup table.
- `kernel::syscall`: Linux numbering, `write` to the console, `exit`/`exit_group`, `ENOSYS`.
- Tests: self-test `user space`; ring 3 program `hello` (write, EFAULT twice, ENOSYS,
  registers kept across syscalls and preemption); `userkernel` and `userhlt` are killed while
  the kernel goes on. 17 tests. Mutation checks: without the fixup table the kernel panics on
  a bad user pointer; without `stac` SMAP blocks the copy.
- xtask keeps the log of every failed boot (with QEMU's stderr) in `build/failed/`; CI
  uploads it.

### Broken / open

- Exited or killed user tasks stay parked in the kernel (task exit is P3).
- Interrupts and exceptions that arrive in the window around `swapgs` from an NMI are not
  specially handled (NMIs are only used to stop the machine).

### Next

- P2: initramfs, ELF loader with auxv, memory syscalls, TLS, ChaCha20 CSPRNG, musl "hello".


## Stage 2, pitstop P2 (musl "hello" runs)

### Done

- `frame::random`: ChaCha20 generator with fast key erasure, seeded from RDSEED, RDRAND
  (CPUID checks, retries, sanity check against stuck values such as the AMD all-ones bug)
  and the TSC; a warning if no hardware source works. Self-test with the RFC 8439 vector.
- xtask builds musl v1.2.6 from its Git repository (commit checked), compiles
  `userspace/*.c` and `userspace/tests/*.c` (static PIE, `*_nopie.c` static at a fixed
  address) and packs them into `build/initramfs.cpio`, loaded by Limine as a module. CI
  caches the musl build.
- Kernel: initramfs reader (cpio newc), ELF loader (ET_EXEC and static PIE, checked against
  the file size, W^X), initial stack with argv, envp and auxv, ASLR, `/init` started at boot.
- Process memory (`kernel::memory`): areas, `brk`, anonymous `mmap` (hint, `MAP_FIXED`,
  `MAP_FIXED_NOREPLACE`), `munmap`, `mprotect` (also `PROT_NONE`), stack growing on demand.
- Syscalls: `write`, `writev`, `ioctl` (`TIOCGWINSZ`), `brk`, `mmap`, `munmap`, `mprotect`,
  `arch_prctl` (FS base, saved per task), `set_tid_address`, `getrandom`, `exit`; faults
  end a process with the signal Linux would send.
- SSE enabled for user programs, with `fxsave`/`fxrstor` on every task switch (musl used SSE
  and got #UD before).
- Tests: 6 C programs (`write`, `memory`, `random`, `startup`, `stack`, `hello_nopie`) run
  in OchraOS and on the host; output and exit status must match. 19 tests. Mutation check:
  without stack growth, `stack` dies with signal 11 and the comparison fails.
- Release image boots and prints "Hello from musl".

### Broken / open

- Exited processes still stay parked (task exit is P3); the test runner polls for the exit.
- `MAP_SHARED` gives `EINVAL` until `fork` exists; `arch_prctl` for the GS base is missing.
- JIT answered by the owner: W^X stays the default, Ochra Guard grants W+X per application
  (stage 7); recorded in `decisions.md` and `security.md`, with the CR4.OSXSAVE note.

### Next

- P3: wait queues, blocking and wake-up from another CPU, task exit; `fork`, `execve`,
  `wait4`, zombies, orphans; file descriptors, pipes, console input; FPU state isolation
  test; stack guard gap (Stack Clash) with a test.


## Stage 2, pitstop P3 (processes, pipes, console)

### Done

- `frame`:
  - every task carries the kernel's data;
  - `fork_user` copies registers, FS base and FPU state;
  - `replace_space` and `reset_fpu` for `execve`;
  - `exit_to`, where the next task on the CPU frees the exited one;
  - `UserSpace::duplicate`;
  - `KernelStack` is freed with a shootdown on every CPU;
  - non-blocking serial `receive`.
- Scheduler: task states under the run queue lock, `WaitQueue` (no lost wake-ups, also
  from another CPU or an interrupt), blocking, task exit.
- Processes:
  - global table, `fork` (eager copy), `execve` (close-on-exec, registers and FPU reset);
  - exit (memory and files released at once, zombie until `wait4`);
  - orphans to init (or collected when there is no init); init ending is a kernel panic.
- Files: `File`/`OpenFile`/`FdTable`, pipes (64 KiB, atomic up to 4096), `/dev/null`-like
  stdin for tests, console with canonical line editing polled on CPU 0.
- Syscalls: `read`, `readv`, `close`, `pipe`, `pipe2`, `dup`, `dup2`, `dup3`, `fcntl`,
  `fork`, `vfork`, `clone` (fork form), `execve`, `wait4`, `getpid`, `getppid`, `gettid`,
  `getpgrp`, `sched_yield`; `write` goes through descriptors.
- Stack guard gap of 256 pages (Stack Clash).
- Tests (20):
  - 12 C programs compared with the host; new ones: `fork`, `exec`, `pipe`, `fds`,
    `fpu`, `fpu_nostart`; `memory` gained a guard gap check;
  - `fpu_nostart` has no libc and checks the registers at `_start` (FCW 0x37F,
    MXCSR 0x1F80, x87/XMM/general registers zero);
  - `fpu` checks that 5 processes keep their own XMM and MXCSR over thousands of switches;
  - the boot test types "ping" on the serial console and `/init` echoes it;
  - `initexit`: init ending panics;
  - no frames leak over two rounds of all test programs. Mutation check: without freeing
    kernel stacks, 216 frames leak and the test fails.

### Broken / open

- `rt_sigprocmask` (musl's `fork` calls it) still gives `ENOSYS`; signals are P4.
- A write to a pipe without readers gives `EPIPE` but no `SIGPIPE` yet.
- Reparenting to a real init is covered by the code path shared with the tests, not by its
  own test; busybox `sh` as init in P4 will exercise it.

### Next

- P4: signals (`rt_sigaction`, `rt_sigprocmask`, `kill`, delivery, `rt_sigreturn`), `EINTR`
  and `SA_RESTART`, `SIGPIPE`, `SIGCHLD`; busybox `sh` as init; boot test with a script; tag
  `stage-2`.
