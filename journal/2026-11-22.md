## Stage 0 code (evening, with Claude Code)

### Done

- Workspace with `kernel/` and `xtask/`, toolchain pinned to Rust 1.99.1 stable.
- Kernel boots through Limine 12.11.1 (built from its SHA-256-pinned source release) in QEMU
  with OVMF; static higher-half ELF with W^X segments.
- COM1 serial driver, coloured `log` backend, Bursztyn the cat in ochre with a pine collar,
  boot log (bootloader, kernel address, direct map, usable memory, command line).
- GDT (Linux selector layout) + TSS with an IST stack for double faults, IDT with naked entry
  stubs for all 32 exceptions, readable crash reports; `int3` self-test on every boot.
- Self-tests `test=pagefault` / `test=doublefault` behind the `selftest` feature (refused in
  release builds).
- `cargo xtask build|run|test`; the test boots three times (normal, page fault, double fault)
  and checks the serial log.
- GitHub Actions: fmt, clippy, build, boot test, DCO check (`.github/scripts/check-dco.sh`).

### Broken / open

- First CI run failed: Limine's configure wanted `llvm-objcopy`, which the Ubuntu runner
  lacks. Fixed by naming all five binutils tools; the second run was green.
- The kernel is a static executable for now; back to PIE for KASLR in stage 1.
- One GDT/TSS/IST stack (per-CPU with SMP), no guard page under the IST stack (needs paging).
